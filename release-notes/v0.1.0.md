# SchemeMode 0.1.0

The first release of SchemeMode: write Processing sketches in Scheme (R7RS), inside the Processing IDE.
Python and the libprocessing engine come in the zip, so there's nothing else to install.

## Install

Download SchemeMode.zip, unzip it into the `modes` folder of your sketchbook (File > Preferences shows
where that is) and restart Processing.

Works on Linux (x86_64), macOS on Apple Silicon and Windows (x64). On Linux it needs glibc 2.34 or
newer (Ubuntu 22.04, Fedora 35, Debian 12 and later).

## Processing's API, in Scheme

- Processing's functions with Scheme names: lowercase with dashes, so `noStroke()` is `(no-stroke)`
  and `mouseX` is `mouse-x`
- `(define (setup) ...)`, `(define (draw) ...)` and the event functions
- Methods take the object first: `v.add(w)` is `(add v w)`, `img.get(x, y)` is `(get img x y)`
- Classes become records (`define-record-type`), Java's arrays become vectors
- Tables, JSON, XML, SVG and OBJ shapes, images and pixels, text, 3D and lights
- All 161 of Processing's Basics and Topics examples, in Scheme, under File > Examples
- Errors point at the line in your Scheme code

## Export Application

- Every platform with a Python in your copy of SchemeMode; the dialog's Install button downloads
  the others
- `<Sketch>.exe` on Windows with your icon built in, a `.app` on macOS, and on Linux a launcher or an AppImage

## Without the IDE

- `processing-scheme-standalone.zip`: every Python, a command-line converter and the examples, with
  `run.sh` and `run.bat` to run a `.scm` sketch from your own editor (needs Java 17 or newer)

## Known gaps

- Intel Macs and Linux on ARM aren't supported yet: the drawing engine isn't built for them

Docs, reference and examples: https://processing-scheme.github.io
