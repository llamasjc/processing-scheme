Write Processing sketches in Scheme, inside the Processing IDE.

Install: download SchemeMode.zip, unzip it into the modes folder of your sketchbook (File > Preferences shows where that is), and restart Processing. Python and the libprocessing engine come in the zip, so there's nothing else to install.

Works on Linux (x86_64), macOS on Apple Silicon and Windows (x64). Intel Macs aren't supported yet.

What's in it:
- Scheme (R7RS) turned into Python and run on libprocessing, on your graphics card.
- setup, draw and the event functions, with Processing's API.
- The examples under File > Examples.
- Errors point at the line in your Scheme code.

On Linux it needs glibc 2.34 or newer (Ubuntu 22.04, Fedora 35, Debian 12 and later).
